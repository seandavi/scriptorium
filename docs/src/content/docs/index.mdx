A collection of AI-assisted skills for scholarly writing — citation
audit, simulated peer review, argumentative-flow analysis — that read
from a shared editorial state file (`MANUSCRIPT_STATE.yaml`) and
ground their critique in a curated, peer-reviewed evidence base.

<Aside type="note" title="Pre-release">
v0.1.0.dev0 is on PyPI. Skills, CLI surface, and the shared-state
schema may change before v0.1.
</Aside>

## Install

```bash
uv pip install --pre agentic-scriptorium
scriptorium install            # Claude Code plugin
scriptorium init ./my-paper    # scaffold MANUSCRIPT_STATE.yaml
```

The [install guide](./how-to/install/) covers the Claude Code, other-agent, and manual paths.
