## What scriptorium is

Most AI writing tools are giant prompts that do one big thing. Scriptorium is an OS for many small things — narrow, inspectable, composable skills that share a single editorial state file and ground their work in a published evidence base.

The docs follow the [Diátaxis](https://diataxis.fr/) framework. Pick your entrance:

- **[Tutorials](/tutorials/)** — learning-oriented walkthroughs. Best place to start if you've never used scriptorium.
- **[How-to guides](/how-to/install/)** — task-oriented recipes for specific problems.
- **[Reference](/reference/cli/)** — precise technical descriptions of the CLI, schema, and plugin manifest.
- **[Concepts](/concepts/design/)** — the *why* behind the design, plus the knowledge layer that grounds every skill.
