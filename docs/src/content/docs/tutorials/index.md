Tutorials are the entrance for new users. They cover scriptorium end-to-end on a real manuscript, with the steps presented as a single linear path.

## Coming with v0.1

- **Your first scriptorium run** — install, scaffold a `MANUSCRIPT_STATE.yaml`, run a critique skill, read the output.
- **Building a `MANUSCRIPT_STATE.yaml` from scratch** — what each field controls and how the choices propagate through skills.
- **Using scriptorium without Claude Code** — the prompt-pack flow for Codex, Gemini, Hermes, etc.

Tracked in [GitHub issue #21](https://github.com/seandavi/scriptorium/issues/21).

In the meantime, [Install](/how-to/install/) is the fastest path to running the CLI, and the [Design](/concepts/design/) page is the fastest path to understanding why the pieces fit together the way they do.
